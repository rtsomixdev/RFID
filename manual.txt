# 📖 คู่มือระบบจัดการผ้าด้วยเทคโนโลยี RFID (Linen Management System)

## 1. ภาพรวมของระบบ (System Overview)
* **ระบบนี้ทำอะไร:** นี่คือระบบสำหรับติดตามผ้า (เช่น ผ้าปูเตียง เสื้อผู้ป่วย) ของโรงพยาบาล ตั้งแต่การเบิกไปใช้ ส่งไปซักที่โรงซัก รับรหัสคืน ไปจนถึงการคัดแยกผ้าที่ชำรุด โดยใช้สายตาของเทคโนโลยีไร้สายที่เรียกว่า "RFID" (เหมือนระบบ EasyPass ทางด่วน) มาช่วยอ่านข้อมูลผ้าทีละหลายๆ ชิ้นพร้อมกัน
* **ใช้ในสถานการณ์แบบไหน:** ใช้ในโรงพยาบาล หรือสถานที่ที่มีผ้าหมุนเวียนจำนวนมากๆ ในแต่ละวัน ช่วยลดภาระการนับผ้าด้วยมือ ลดความผิดพลาด และป้องกันผ้าสูญหาย
* **องค์ประกอบหลักของระบบมีอะไรบ้าง:**
  1. เครื่องอ่านสแกนเนอร์ (RFID Reader)
  2. เว็บไซต์สำหรับผู้ใช้งานกดเบิก-รับ-ดูรายงาน (Frontend)
  3. สมองกลประมวลผลข้อมูล (Backend)
  4. ตู้เก็บข้อมูลหรือฐานข้อมูล (Database)

## 2. โครงสร้างโปรเจค (Project Structure)
โครงสร้างโฟลเดอร์ต่างๆ ในระบบ ถูกแบ่งหน้าที่ทำงานเหมือนพนักงานในบริษัท:
* `Frontend`: หรือ **"พนักงานต้อนรับ"** เป็นหน้าตาของระบบ (หน้าเว็บไซต์) ที่คนทั่วไปสามารถมองเห็น คลิกปุ่ม พิมพ์ข้อความค้นหา หรือดูรายงานสวยๆ
* `Backend`: หรือ **"ผู้จัดการศูนย์สั่งการ"** ไม่เห็นตัวแต่คอยประมวลผลหลังบ้าน รับคำสั่งจากหน้าเว็บ แล้วคำนวณหรือตรวจสอบข้อมูลก่อนจะสั่งให้ไปบันทึกลงฐานข้อมูล
* `database` / `pgadmin-data`: หรือ **"ตู้เซฟเก็บเอกสาร"** เก็บข้อมูลทุกอย่าง เช่น ใครเบิกผ้า ผ้ามีกี่ชิ้น สถานะเป็นอย่างไร
* `mosquitto`: หรือ **"พนักงานไปรษณีย์"** ทำหน้าที่คอยยืนรับส่งข้อความความเร็วสูงระหว่างเซ็นเซอร์อ่านป้าย RFID กับสมองกล
* `docker-compose.yml`: หรือ **"สูติบัตรและแผนผังบริษัท"** ไฟล์นี้มีหน้าที่เสกพนักงานทุกฝ่ายให้ตื่นขึ้นมาทำงานพร้อมๆ กันได้ในคำสั่งเดียว

## 3. เทคโนโลยีที่ระบบใช้ (Technology Stack)
* **ภาษาโปรแกรม:** 
  * TypeScript (ใช้สร้างหน้าเว็บไซต์ Frontend)
  * C# (ใช้สร้างสมองกล Backend)
* **Database (ฐานข้อมูล):** ใช้ "PostgreSQL" ซึ่งเป็นฐานข้อมูลระดับโลกที่มีความเสถียรและเก็บบันทึกข้อมูลได้มหาศาล
* **ระบบตัวกลางเชื่อมต่อเครื่องอ่าน:** ใช้ "MQTT (Mosquitto)" แบบเดียวกับที่ใช้ในระบบบ้านอัจฉริยะ (Smart Home) ข้อมูลเด้งไวไม่ต้องรอโหลด
* **Container:** ใช้ "Docker" ซึ่งเปรียบเสมือนกล่องวิเศษ ที่แพ็คโปรแกรมทั้งหมดไว้พร้อมใช้ คุณไม่ต้องไปติดตั้งโปรแกรมย่อยๆ ทีละตัวให้วุ่นวาย

## 4. สิ่งที่ต้องติดตั้งก่อนใช้งาน (Prerequisites)
ผู้อ่านจำเป็นต้องติดตั้ง **Docker Desktop** ไว้ที่คอมพิวเตอร์ก่อนการใช้งาน (ทำเพียงครั้งเดียว):
1. เข้าไปที่เว็บไซต์: https://www.docker.com/products/docker-desktop/
2. กดปุ่ม **Download for Windows** (หรือ Mac หากใช้เครื่อง Mac)
3. เมื่อดาวน์โหลดเสร็จ ให้ดับเบิ้ลคลิกไฟล์เพื่อติดตั้ง และกด "Next/Ok" ไปเรื่อยๆ จนจบการทำงาน
4. รีสตาร์ทเครื่องคอมพิวเตอร์ 1 ครั้ง 
5. เปิดโปรแกรม Docker Desktop ขึ้นมา (อาจต้องกด Accept เงื่อนไขการใช้งานเบื้องต้น)

## 5. วิธีติดตั้งระบบ (Installation Guide)
เมื่อมีโปรแกรม Docker แล้ว การติดตั้งและเริ่มต้นระบบมีดังนี้:

**Step 1:** นำโฟลเดอร์โปรเจคชื่อ `RFID` ไปวางไว้ในคอมพิวเตอร์ (เช่น หน้า Desktop)
**Step 2:** กดเปิดโปรแกรม `Docker Desktop` ทิ้งไว้ให้ทำงานอยู่หลังบ้าน
**Step 3:** เข้าไปในโฟลเดอร์ `RFID`
**Step 4:** พิมพ์คำว่า `cmd` ตรงช่องพิมพ์ที่อยู่ด้านบนสุดของโฟลเดอร์ (Address Bar) แล้วกดปุ่ม `Enter` (หน้าต่างจอสีดำจะเด้งขึ้นมา)
**Step 5:** พิมพ์คำสั่งร่ายมนต์เพื่อเปิดระบบ (คัดลอกลงไปแปะได้เลย): 
`docker-compose up -d --build` 
จากนั้นกด `Enter`
**Step 6:** รอให้ระบบดาวน์โหลดเครื่องมือและประกอบร่าง อาจใช้เวลา 3-10 นาที (ทำแค่นานครั้งแรกครั้งเดียว) 

## 6. วิธีเปิดใช้งานระบบ (How to Run the System)
หลังจากพิมพ์คำสั่งในขั้นตอนที่ 5 แล้วเสร็จ **ระบบทุกส่วนจะถูกเปิดทำงานอัตโนมัติ** คุณสามารถเข้าใช้งานได้ทันทีดังนี้:

* **เปิดหน้าเว็บไซต์ (Frontend):** 
  เปิดเบราว์เซอร์ (Google Chrome, Edge) แล้วพิมพ์ URL ว่า `http://localhost:3000` คุณจะเจอหน้าเข้าสู่ระบบของเว็บไซต์ 
* **ตัวจัดการระบบฐานข้อมูล (pgAdmin - พิเศษเฉพาะแอดมิน):**
  เข้าผ่าน URL: `http://localhost:5050`
  *(อีเมล: admin@linen.com / รหัสผ่าน: 123456)*
* **ระบบหลังบ้าน (Backend API):** 
  รันอยู่แบบซ่อนตัวอยู่ที่ URL `http://localhost:8080` (เอาไว้ให้ระบบหน้าเว็บกับ RFID วิ่งมาคุยด้วยเท่านั้น) 

## 7. วิธีตรวจสอบว่าระบบทำงานถูกต้อง (Verification)
มีจุดให้เช็ค 2 ที่ด้วยกัน:
1. **เช็คบนแอป Docker Desktop:** ถ้าเปิดหน้าต่างแอป Docker ขึ้นมา คุณต้องเห็นรายชื่อ Container (กล่องระบบ) เช่น `db`, `pgadmin`, `mosquitto`, `backend`, `frontend`, `tunnel` ทั้งหมดขึ้นสถานะจุด **สีเขียว (Running)**
2. **เช็คการเปิดเว็บ:** เมื่อเข้า `http://localhost:3000` หน้าเว็บจะต้องโหลดขึ้นมาสมบูรณ์ ไม่ขึ้นหน้าจอขาว หรือหน้า Page Not Found

## 8. โครงสร้างฐานข้อมูล (Database Explanation)
ข้อมูลในตู้เซฟของเราแบ่งเป็นแฟ้ม (Table) หลักๆ ให้อ่านเข้าใจง่ายดังนี้:

* **User (ผู้ใช้งาน):** เก็บข้อมูลบุคคลที่เข้าใช้งานเว็บ เช่น ชื่อ นามสกุล รหัสผ่าน
* **Hospital / Ward / Room (แผนกจัดเก็บ):** เก็บข้อมูลชื่อโรงพยาบาล ตึก วอร์ด และห้องต่างๆ ที่ผ้าแต่ละชิ้นถูกแจกจ่ายไปอยู่
* **Product (ชนิดผ้า):** เก็บว่าผ้าชนิดนี้คืออะไร เช่น ผ้าห่ม ผ้าปูเตียง สีอะไร เป็นแบบใช้แล้วทิ้งไหม
* **Linen (ตัวผ้าแต่ละผืน):** ผ้าแต่ละผืนบนโลกแห่งความเป็นจริง จะถูกฝังชิปที่มีรหัสไม่ซ้ำกัน ข้อมูลส่วนนี้จะเก็บ "รหัสชิป" โยงไปหาว่ามันคือผ้าชนิดไหน และปัจจุบันใช้งานไปกี่ครั้ง ถูกเก็บอยู่ที่ตึกไหน
* **Request (ใบเบิก/ส่งซัก):** เก็บข้อมูลตั๋วคำขอส่งผ้าไปซัก หรือตั๋วขอเบิกของใหม่
* **LinenLog (ประวัติการเดินทาง):** เปรียบเสมือน Passport ของผ้า ระบบจะปั๊มตราประทับทุกครั้งเวลาเดินผ่านประตู RFID ว่าผ่านประตูไหน เมื่อไหร่

## 9. การทำงานของระบบ (System Workflow)
ลองจินตนาการภาพการทำงานเป็นสายน้ำแบบนี้ครับ:
1. **คนเข็นรถผ้าเดินผ่านประตู:** เครื่องสแกนที่ประตูอ่านเจอชิปผ้า 50 ชิ้นพร้อมกัน
2. **เครื่องอ่านส่งเสียงไซเรนไปหาไปรษณีย์:** เครื่องอ่านโยนรหัสของผ้าทั้ง 50 ชิ้น วิ่งผ่านท่อ "mosquitto" แบบความเร็วสูง
3. **ไปรษณีย์ส่งจดหมายให้ศูนย์สั่งการประมวลผล (Backend):** สมองกล Backend จะจับรหัสทั้ง 50 ตัวมาเปิดสมุดเซฟตาราง "Linen" เพื่อเช็คว่า อ๋อ! รหัสนี้คือผ้าปูเตียงไซส์ L ของตึก A นะ
4. **บันทึกลงตู้เซฟ (Database):** ตู้เซฟจะอัพเดทสถานะให้เลยว่า วันนี้เวลานี้ ผ้าผืนนี้กำลังออกจากตึก
5. **แสดงผลหน้าเว็บ (Frontend):** เมื่อมีคนเปิดหน้าเว็บหน้าจอจะเด้งรายชื่อและจำนวนผ้าแบบสดๆ (Real time) โดยไม่ต้องกดรีเฟรช 

## 10. วิธีดู log และแก้ปัญหาเบื้องต้น (Troubleshooting)
หากระบบรันไม่ได้ หรือเกิดเหตุขัดข้อง ลองแก้ตามขั้นตอนนี้ครับ:
* **ปัญหาเปิดหน้าเว็บไม่ขึ้น / สตาร์ทไม่ติด:** 
  เปิดแอป `Docker Desktop` หาโปรเจคชื่อ `rfid` ถ้ามีกล่องไหนหยุดทำงาน(เป็นสีเทา) ให้กดปุ่ม `Play (▶)` ด้านหลังชื่อนั้นเพื่อเปิดเครื่องใหม่
* **หน้าเว็บ Error เชื่อมต่อฐานข้อมูลไม่ได้:** 
  เช็คว่ากล่องที่ชื่อ `db` เป็นสีเขียวหรือไม่ ถ้ากล่อง `db` เพิ่งถูกเปิด บางทีศูนย์สั่งการ (Backend) อาจจะบูทระบบเร็วกว่า ให้กดปุ่ม Restart (ไอคอนหมุนวน) ที่กล่อง `backend` อีกสักครั้ง
* **ปัญหา Port ชนกัน (Port Already in Use):** 
  เช่นคอมพิวเตอร์ของคุณมีโปรแกรมจำลองฐานข้อมูลตัวอื่น (XAMPP, MySQL) หรือมีโปรแกรมมารอใช้งานหมายเลขช่องเสียบ 8080 หรือ 3000 ให้ทำการปิดโปรแกรมเหล่านั้นก่อนรันคำสั่ง  

## 11. แนวทางพัฒนาต่อในอนาคต (Future Development Guide)
หากคุณส่งต่อโปรเจคนี้ให้กับนักพัฒนา (Developer) หรือโปรแกรมเมอร์ในรุ่นถัดไป นี่คือสิ่งสำคัญที่เขาควรทำเพื่อแต่งเติมโปรเจคให้สมบูรณ์ขึ้นไปอีก:
1. **เพิ่ม Feature ตารางสรุปรูปแบบกราฟ (Dashboard & Analytics):** เชื่อมยอดการส่งซักรายเดือนออกมาเป็นกราฟสวยๆ ให้ผู้บริหารดูได้ง่ายขึ้น
2. **ระบบการแจ้งเตือนพกพา (Line Notify / SMS):** ให้ส่งข้อความเข้ามือถือแอดมิน เมื่อมีตั๋วงานด่วน หรือมีผ้าถูกแอบขนออกนอกเส้นทางที่ขีดไว้
3. **การปรับเปลี่ยนหน้าตาแบบ Custom (Theming):** รองรับการเปลี่ยนสีเว็บไซต์และโลโก้ ให้ปรับเปลี่ยนตามแบรนด์ของโรงพยาบาลอื่นๆ ที่รับระบบไปติดตั้งได้อย่างอิสระโดยไม่ต้องแก้โค้ดชิ้นอื่น
4. **Scale ระบบเมื่อเข้าสู่สถานการณ์จริงแบบเข้มข้น (Production Readiness):** แยกฐานข้อมูล `db` จากเดิมที่อยู่ในกล่อง Docker ไปไว้ใน Cloud Database (เช่น ของ AWS หรือ Azure) เพื่อป้องกันข้อมูลสูญหาย และลดภาระการทำงานหนักของคอมพิวเตอร์เครื่องนี้
